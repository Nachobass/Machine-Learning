# Machine Learning Course - Practical Works

This repository contains all practical works (TPs) for the Machine Learning course. Each TP focuses on different aspects of machine learning, from basic linear models to advanced deep learning and unsupervised learning techniques.

## Course Overview

The course covers fundamental and advanced machine learning concepts through hands-on implementation and analysis. All algorithms are implemented from scratch to ensure deep understanding of the underlying mathematics and principles.

## Practical Works

### [TP1 - Linear Regression and Feature Engineering](./Basso_Ignacio_TP1/)
**Focus**: Supervised Learning - Regression
- Custom linear regression implementations
- Feature engineering for real estate data
- Regularization techniques (L1/L2)
- Gradient descent optimization
- **Key Skills**: Mathematics of linear models, optimization, feature selection

### [TP2 - Classification Problems](./Basso_Ignacio_TP2/)
**Focus**: Supervised Learning - Classification  
- Binary and multi-class classification
- Logistic regression implementation
- Class imbalance handling
- Medical diagnosis and sports analytics applications
- **Key Skills**: Classification metrics, probability theory, imbalanced data

### [TP3 - Deep Learning and Neural Networks](./Basso_Ignacio_TP3/)
**Focus**: Deep Learning
- Custom neural networks with PyTorch
- Image classification tasks
- Network architecture design
- Advanced optimization techniques
- **Key Skills**: Deep learning frameworks, computer vision, network design

### [TP4 - Unsupervised Learning and Clustering](./Basso_Ignacio_TP4/)
**Focus**: Unsupervised Learning
- K-Means, DBSCAN, and GMM clustering
- Principal Component Analysis (PCA)
- Variational Autoencoders (VAE)
- Model evaluation for unsupervised methods
- **Key Skills**: Dimensionality reduction, clustering evaluation, generative models

## Technology Stack

- **Languages**: Python
- **Core Libraries**: NumPy, Pandas, Matplotlib
- **ML Framework**: PyTorch (for deep learning components)
- **Development**: Jupyter Notebooks
- **Documentation**: LaTeX reports

## Getting Started

1. **Clone or navigate to any TP folder**
2. **Install dependencies**: `pip install -r requirements.txt`
3. **Run the Jupyter notebook** for the specific TP
4. **Refer to individual README files** for detailed instructions

## Learning Progression

The TPs are designed with increasing complexity:

1. **TP1**: Foundation - linear models and basic ML concepts
2. **TP2**: Classification - extending to discrete predictions
3. **TP3**: Deep Learning - neural networks and modern ML
4. **TP4**: Unsupervised - learning without labels

## Key Learning Outcomes

- **Mathematical Understanding**: Implementation from scratch ensures deep comprehension
- **Practical Skills**: Real-world datasets and problems
- **Modern Tools**: Industry-standard libraries and frameworks
- **Evaluation**: Proper metrics and validation techniques
- **Documentation**: Professional reporting and code documentation
